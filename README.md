🚀 Full Stack Web Application

Aplikasi web Full Stack yang dibangun menggunakan teknologi web fundamental hingga modern untuk menghasilkan aplikasi yang responsif, interaktif, terhubung dengan database, dan dapat digunakan secara offline melalui Progressive Web App (PWA).

Project ini mencakup implementasi Frontend, Backend, REST API, AJAX, Fetch API, JSON, Authentication, Database, dan PWA.
